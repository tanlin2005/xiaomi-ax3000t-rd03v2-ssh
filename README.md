# 小米 AX3000T 高通版 (RD03v2) 原厂固件 SSH 永久解锁与撤销工具

专为**小米路由器 AX3000T 高通版**（硬件版本代号：`RD03v2`，高通 IPQ5018 处理器）定制的原厂固件免拆机 Root / 开启 SSH 及持久化固化管理工具。

本工具针对 Windows 11 环境进行了专属优化，具备友好的开箱即用体验。

---

## ✨ 项目特性

- **纯 Python 原生标准库实现**：无须 `pip install` 任何第三方包，只要系统有 Python 3 即可直接运行。
- **免克隆任何外部源码**：将 Mesh 认证握手、密码凭据泄露抓取、命令注入触发与载荷分发单文件全内置。
- **免拆机 / 免接串口 (No UART)**：利用官方固件底层 Mesh 组网漏洞直接在原厂系统提权，不伤外壳与保修。
- **双向可逆管理**：
  - **[1] 开启 SSH 并固化**：支持自定义设置 root 密码，自动写入 NVRAM/BDATA，通过持久化脚本与防火墙机制实现跨重启/中继模式持久生效；
  - **[2] 撤销 Root 并关闭 SSH**：彻底停用并关闭 Dropbear/Telnet 服务，清除 NVRAM 标记、持久化脚本与定时任务，锁定 root 密码并完全无痕恢复至官方出厂状态。
- **双工作模式支持**：深度适配普通路由模式与有线/无线中继 (AP) 模式，内置防中继模式重置配置的防覆盖自愈机制。
- **Windows 11 专属优化批处理**：
  - 透明友好的 UAC 管理员提权说明；
  - 自动在 Windows 防火墙中临时放行传输端口，避免 Win11 因公用网络阻止连接导致路由器无法下载载荷；
  - 脚本执行完毕自动清理临时防火墙规则，保持系统安全洁净。

## 🚀 使用指南 (Windows 11)

### 1. 准备工作
1. 确保电脑已安装 Python 3（可直接在 Win11 微软应用商店 Microsoft Store 搜索并安装 `Python 3.11` 或 `3.12`）。
2. 将路由器恢复出厂设置（长按背部 Reset 键约 8 秒至指示灯闪烁后松开）。
3. 路由器重启后，**切勿进入网页进行任何初始化配置**，保持未配置向导状态。
4. 使用网线将电脑的网口与路由器的任意网口直连。

### 2. 运行工具
在 Windows 11 中直接双击运行 **`一键开启SSH与固化.bat`**：

1. **UAC 提示**：批处理会展示清晰的权限说明，直接按回车调起管理员授权（用于临时放行入站规则，防止 Win11 防火墙拦截）。
2. **选择操作**：
   - 输入 `1`：**开启 SSH 并固化**。可输入自定义 root 密码（回车默认 `admin`），选择工作模式（路由或中继）。
   - 输入 `2`：**撤销 Root 并关闭 SSH**。确认后将完全抹除所有注入与固化配置，锁定 root 密码并还原为未解锁状态。
3. **完成配置**：
   - 解锁成功后，打开浏览器访问 `http://192.168.31.1`，路由器会重新展示官方开箱向导，你可以正常配置你的 WiFi 与上网设置，后台的 SSH 权限已持久化常驻。
   - 在终端使用 SSH 即可登录路由器底层：
     ```powershell
     ssh root@192.168.31.1
     ```
